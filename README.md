# 체크리스트 (GitHub Pages, 기기별 저장)

GitHub Pages로 여는 체크리스트 사이트입니다. 서버도, 로그인도 없습니다.

- 목록과 체크는 **각 기기 브라우저(localStorage)에만** 저장됩니다. 다른 사람이나 다른 기기와 자동으로 공유되지 않습니다.
- 처음 열면 기본 목록(`docs/default-data.json`)으로 시작합니다. 이 파일은 공개되므로 전화번호 같은 개인 정보는 넣지 마세요.
- **기본 목록 바꾸기**: GitHub에서 `docs/default-data.json`만 고치면 됩니다. 빌드는 필요 없고, Pages 반영까지 몇 분 걸릴 수 있습니다.
  - 목록을 직접 편집하지 않은 기기는 다음에 열 때 새 기본 목록으로 바뀝니다. 같은 항목(id)의 체크는 유지됩니다.
  - 목록을 편집했거나 링크로 목록을 넣은 기기는 그 기기의 목록을 유지합니다. 편집 화면 맨 아래 **기본 목록으로 되돌리기**로 새 기본 목록을 받을 수 있습니다.
  - 항목의 `id`를 바꾸면 그 항목의 체크는 사라집니다. 문구만 고칠 때는 `id`를 그대로 두세요.
- 기기에 저장된 목록은 **편집**에서 고칠 수 있고, 고친 내용은 그 기기에만 남습니다.
- 다른 목록은 **목록 링크**(`…/#list=…`)를 열어서 넣을 수 있습니다.
- 링크의 `#` 뒷부분에 목록과 체크가 압축되어 들어 있습니다. 이 부분은 웹 서버로 전송되지 않습니다.

## 사이트 켜기 (GitHub Pages)
저장소 **Settings → Pages → Build and deployment**
- Source: **Deploy from a branch**
- Branch: **main**, 폴더 **/docs** → Save

몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

> 위 메뉴 이름은 작성 시점에 GitHub 문서로 확인하지 못했습니다. 화면과 다르면 비슷한 메뉴를 찾아 주세요.

## 사용
- **편집**: 제목, 담당자 이름, 섹션, 소제목, 항목, 하위 항목을 추가·수정·삭제·순서 변경할 수 있습니다.
- **다른 기기로 옮기기 · 백업 링크 복사**: 지금 목록과 체크가 담긴 링크를 만듭니다. 다른 기기에서 열면 그대로 옮겨지고, 메모에 보관해 두면 백업이 됩니다.

## 주의
- 브라우저의 사이트 데이터를 지우거나 사생활 보호(시크릿) 창을 쓰면 저장된 내용이 사라집니다.
- 일부 브라우저(특히 iPhone Safari)는 오래 방문하지 않은 사이트의 저장 데이터를 지울 수 있습니다. 홈 화면에 추가해 두고, 가끔 백업 링크를 만들어 두세요.

## 코드 수정
`src/app.js`를 고친 뒤 다시 빌드합니다. (`docs/default-data.json`은 빌드가 필요 없습니다.) 결과는 `docs/app.js`에 만들어집니다.

```bash
npm install && npm run build
```

# 육아휴직 통합 관리 대시보드 (`docs/parental-leave/`)

육아휴직 일정, 사업장 지원금(대체인력·업무분담·육아휴직 지원금), 6+6 부모육아휴직 월별 급여를 보는 페이지입니다.

- 주소: `https://<아이디>.github.io/<저장소이름>/parental-leave/` (위 "사이트 켜기"가 되어 있어야 열립니다.)
- **금액은 모두 예시값**입니다. 통상임금·월 급여·추가 수입·자녀 출생일은 화면에서 직접 입력하며, 입력값은 **각 기기 브라우저(localStorage)에만** 저장됩니다.
- 지원금·급여 기준은 고용노동부 일생활균형 안내(2026.11.06 열람)를 따랐습니다. 단, 6+6 5개월차 상한은 안내 페이지 표기(350만원) 대신 400만원을 적용했습니다. 실제 금액은 고용24 또는 1350에서 확인하세요.
- `d3.min.js`는 d3 v7.9.0(ISC 라이선스, Copyright 2010-2023 Mike Bostock)입니다.

# 사업장 지원금 일정표 (`docs/subsidy-gantt/`)

대체인력 지원금(휴직 전 인수인계 · 육아휴직 기간 · 복직 후 인수인계)과 육아휴직 지원금(남성 육아휴직 인센티브 포함)의 지원 기간, 신청 일자, 마감, 제출 서류를 간트차트로 보는 페이지입니다. (우선지원대상기업 · 30인 미만 기준)

- 주소: `https://<아이디>.github.io/<저장소이름>/subsidy-gantt/`
- 근로자 육아휴직 기간, 대체인력 고용 기간, 대체인력 월 임금을 입력하면 다시 계산합니다. 입력값은 각 기기 브라우저에만 저장됩니다.
- 신청서 서식(별지 제25호 · 제26호)은 국가법령정보센터 파일로 연결됩니다.
