# 체크리스트 (GitHub Pages, 기기별 저장)

GitHub Pages로 여는 체크리스트 사이트입니다. 서버도, 로그인도 없습니다.

- 목록과 체크는 **각 기기 브라우저(localStorage)에만** 저장됩니다. 다른 사람이나 다른 기기와 자동으로 공유되지 않습니다.
- 이 저장소에는 사이트 코드만 있고, 목록 내용은 없습니다.
- 목록은 **목록 링크**(`…/#list=…`)를 한 번 열어서 넣거나, **편집**에서 직접 만듭니다.
- 링크의 `#` 뒷부분에 목록과 체크가 압축되어 들어 있습니다. 이 부분은 웹 서버로 전송되지 않습니다.

## 사이트 켜기 (GitHub Pages)
저장소 **Settings → Pages → Build and deployment**
- Source: **Deploy from a branch**
- Branch: **main**, 폴더 **/docs** → Save

몇 분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소로 열립니다.

> 위 메뉴 이름은 작성 시점에 GitHub 문서로 확인하지 못했습니다. 화면과 다르면 비슷한 메뉴를 찾아 주세요.

## 사용
- **편집**: 제목, 담당자 이름, 섹션, 소제목, 항목, 하위 항목을 추가·수정·삭제·순서 변경할 수 있습니다.
- **다른 기기로 옮기기 · 백업 링크 복사**: 지금 목록과 체크가 담긴 링크를 만듭니다. 다른 기기에서 열면 그대로 옮겨지고, 메모에 보관해 두면 백업이 됩니다.

## 주의
- 브라우저의 사이트 데이터를 지우거나 사생활 보호(시크릿) 창을 쓰면 저장된 내용이 사라집니다.
- 일부 브라우저(특히 iPhone Safari)는 오래 방문하지 않은 사이트의 저장 데이터를 지울 수 있습니다. 홈 화면에 추가해 두고, 가끔 백업 링크를 만들어 두세요.

## 코드 수정
`src/app.js`를 고친 뒤 다시 빌드합니다. 결과는 `docs/app.js`에 만들어집니다.

```bash
npm install && npm run build
```
